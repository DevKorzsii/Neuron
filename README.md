# LuaLearn

- Free desktop app for learning Roblox Luau scripting.

<img width="1452" height="865" alt="Screenshot 2026-08-04 205707" src="https://github.com/user-attachments/assets/f3d5c77b-7d39-4313-bc32-58702d277b17" />

## What it does
- 43 lessons, beginner to advanced — variables through DataStores,
  remotes, pathfinding and security
- 10 guided build projects, made step by step with the reasoning
  behind every line
- Quizzes with instant feedback and a review queue for what you missed
- Built-in Lua runner that explains real error messages in plain English
- Progress saved locally, points and unlockable themes

## Install
- Download the latest `LuaLearn.exe` from [Releases](../../releases/latest).
- Windows 10/11.

## Build it yourself
- Requires Python 3.10+.
